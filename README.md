
### 📰 Dragon News – News Portal Application

A dynamic and responsive news portal application built with React. Users can explore news articles by different categories, read detailed news, and securely access the application through Firebase Authentication.

**✨ Key Features:**
- 📰 Browse news articles by categories.
- 🔐 User authentication with Firebase.
- 🔑 Email and password-based login and registration.
- 🌐 Google and GitHub social login.
- 🛡️ Protected routes for authenticated users.
- 📖 Detailed news article viewing.
- 📱 Responsive design for different devices.
- ⚛️ Context API for global state management.

**🛠️ Technologies:**
React.js, React Router, JavaScript (ES6+), Firebase Authentication, Tailwind CSS.
